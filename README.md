# UniPortal

University management system built with Spring Boot.

## Author

Gleb Zapara

## Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Liquibase
- Thymeleaf
- Cloudflare R2 (S3)

## Features

- Admin management
- Student management
- Teacher management
- Groups and departments
- Subjects and lessons
- Grade management
- Schedule management
- Image storage via Cloudflare R2
